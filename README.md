# 小芽识字屋

原创家庭识字小网站。保留基础 35 字，新增一组连贯的进阶故事课，并用月历回看真实学习记录。Python/SQLite + 原生 HTML/CSS/JavaScript，无第三方运行时 Python 包、账号或追踪。

## 当前能用什么

| 区域 | 已有内容 | 不代表什么 |
| --- | --- | --- |
| 基础区 `sprout-2` | 原 7 课、35 字和原练习；可续学、再次复习 | 旧完成不会占用进阶第 1～7 课，也不自动登记掌握 |
| 进阶区 `sprout-3` | 原创 7 课、35 个不重复的新字，小兔从出门到读书的故事线 | 不是外来教材复刻，尚未完成真实家庭教学试用 |
| 长期路线图 | 累计认读节点 300 → 800 → 1500 → 2200 → 3000 | **目前只发布 70 个不同目标字，不是已经完成 3000 字课件** |
| 学习日历 | 月份切换、日期详情、课程筛选、新学卡/复习/完成/来源 | 小步、完成、接触和掌握是不同口径；不显示虚构用时 |

分级是课程规划工具，不是年龄标准或掌握保证。家长可设置目标字数与日期；默认保持每天 5 个新字、约 20 分钟参考，不因日期临近自动加量，不预填已学事件。未生产阶段明确标注“规划中”，不可进入空课。

**自然音频尚未就绪。** 仓库不含许可未核实的 86 段旧 WAV，也不含新课自然音频。可以完整使用成人带读或静音练习；这不是自然语音或儿童独立认读能力已验收的版本。补图版本已通过托管 Chromium 的 7 项真实浏览器检查（桌面/平板三种视口），但这不是安卓实机、真实触摸/声音或 Docker/NAS 部署验收，也不是无 bug 保证。准确提交、运行链接与测试边界见 [STATUS.md](STATUS.md)。

## 启动（仅可信电脑或家庭网络）

需要 Python 3.11+ 与时区数据库，Linux/macOS；Windows 建议使用 Linux 容器。运行不需要 npm。

```bash
python3 server.py
```

在同一执行环境的浏览器打开 `http://127.0.0.1:8080`。默认仅监听本机，匿名记录存于 `data/progress.sqlite3`。每个数据目录只运行一个实例。

经家长确认家庭网络可信、主机 IP 和防火墙后，才考虑局域网运行：

```bash
DATA_DIR=/你的专用学习目录 APP_TIMEZONE=Asia/Shanghai python3 server.py --host 0.0.0.0 --port 8080
```

另一台平板要访问服务器实际局域网 IP，不是平板自己的 127.0.0.1。**应用无身份认证，不可暴露公网、端口映射或公网转发。** 家长算术门槛只防误触，不是安全密码；能访问服务的人可能看到记录和下载备份。

## 学习方式

进阶新字、词语和故事已配原创教学图：35 个字、35 个词条（34 个不同词语）与 14 个故事片段。听音及听音式复习仍使用中性角色，不用目标图透出答案；关系词/代词等仍需成人结合语境讲解。

1. 首页默认进入进阶故事课；“基础 35 字”独立保留原课程。每课是顺序，不是日历截止日。
2. 每一步明确选择“成人已带读 / 讲解”或“静音看字 / 对照练习”。成人提示默认折叠，成人带读时先不让孩子看提示。
3. 静音遇到原听音题时会明确显示对照提示，变为对照选字练习；不伪称完成听辨或自主认读。基础区若本地合法音频存在，可尝试播放；失败后仍能改选替代方式。
4. 认识字后进入词语、共读、理解和短句。未教支撑字由大人辅助；“我/你”交换说话角色，“朋/友/们”放在句子中理解。独立看短句只是练习，不是无提示掌握检查。
5. 对错反馈有文字和形状，不仅靠颜色。作答后必须手动“下一小步”，不会自动跳题。随时暂停，服务器确认的步骤会保留。
6. 每课首次完成固定 1 朵花。已完成的课可新开复习实例，未完复习可继续；复习记录保留，但不重复发花、不重复累计新字。

课程完成、答对选择题、播放声音、带读和看图都不足以证明稳定认读。当前未实现无提示认读证据录入、逐字稳定性评估、自动跳过已会字或自适应长期复现调度；这些是后续功能，不能由练习状态冒充。家长页明确为“尚未评估”，不会自动登记已掌握字数。没有录音、语音打分、排行榜或签到惩罚。

## 日历的时间与统计口径

- `APP_TIMEZONE` 在创建/迁移数据库时固定，默认 `Asia/Shanghai`；后续改变部署环境时区不会悄悄移动已有日期。前端使用服务端 ISO 日期键。
- 新事件在写入本机暂存时捕获设备报告的发生时间，重试不改时间；服务器另外保存接收时间。合理设备时间用于分日，跨午夜迟到同步仍可落在发生日。
- 无效时区/时间、明显快钟、会落在未来日的设备时间使用**保存日期**并标明来源；原客户端时间仍保存在原始提交内容中。
- 旧版没有发生时间，只能标为“旧版记录按保存日期统计”，无法倒推出真实作答日，不能用课次补造历史。
- 新学卡是当天练过的 `learn` 字；复习是 `review` 或再次练习实例中的字。听音/配词等另列练习表现；完成只计实际最后一步所在日。
- 空日和未来日中性显示“暂无已保存记录”。待同步操作不进入已保存日历。没有学习分钟数或将经过天数转换为掌握量的规则。

## 断连、刷新、多标签

每个事件独立暂存，保留事件 ID、课程/课次/复习实例、方式、发生时间及数据库恢复代次。断连后停止继续答题，**不是离线学习/PWA**。不要清浏览器数据，恢复连接后点“重新连接并同步”；同 ID 同内容只保存一次。

旧 `sprout-pending-v2:` 队列保留原 payload，只能投向基础 `sprout-2`，不会套到新课。多标签不会互删暂存。遇到冲突或恢复前队列，先核对服务器；先点“核对服务器进度（保留暂存）”查看冲突，再单独点“确认放弃这条暂存”才丢弃该条，未点击前不会静默清除。浏览器存储损坏/受限会阻止提交，并明确要求核对。

## 从旧公开版本升级

先停止服务、关闭学习页面，核对并同步待提交操作，另存一份备份；保留整个原数据目录。仅替换应用代码和静态文件，不要用演示/测试数据覆盖原目录。

- `course.py` 是冻结的 `sprout-2` 解释器；新目录在 `curriculum.py`。**数据库 `schema_version=3` 与课程版本分离。**
- 首次启动识别有效旧库后，先保留 `progress.sqlite3.pre-migration-随机标记` 一致快照，再在暂存库迁移、完整验证后原子替换。原事件 ID、payload、答案、保存时间和固定奖励归基础区。
- 重启不会重复迁移。未知课件/损坏记录拒绝猜测；迁移失败保留原库。若主库缺失却存在 WAL/SHM/journal，拒绝建立新库，不擅自删恢复日志。
- 不从旧“完成”推断任何孩子已掌握的字，也不把旧数据改记为新课程进度。

若需回退旧程序：先停服务并保存当前 schema3 备份，使用匹配的迁移前副本与旧程序；旧程序不能直接读 schema3。回退只包含原备份时的事实，之后新增记录不会自动合并。不要手工删除未知数据库日志或混用两个实例。

## 备份与恢复

家长页下载 SQLite 在线一致快照。备份含匿名答题时间和可能私有的目标日期，请只存可信设备，不公开上传。

先停止服务、核对原页面待同步记录，再执行：

```bash
python3 scripts/restore.py /备份路径/sprout-backup.sqlite3 --data-dir ./data --confirm RESTORE
python3 server.py
```

恢复会检查完整性、结构、课程/任务快照、**全部事件**的顺序与派生字段、奖励和配置；不再限制少于 1000 条。先验证暂存副本、保存 `.pre-restore-日期-随机标记`，再原子替换。运行中服务、目标残留日志、损坏/未知备份会安全拒绝，不删除未知 sidecar。

旧版备份没有时区字段，优先沿用目标库固定时区，否则使用 `APP_TIMEZONE`；如原统计时区不同，请显式指定，例如 `--timezone America/New_York`。当前版本备份保留源库已固定时区，不受损坏目标元数据干扰。恢复不修改所选源备份。

恢复后会更新数据库代次：原队列中已存在的同内容事件可确认；尚未保存的旧代次/旧版事件不会自动写入回退后的库。刷新页面并明确核对暂存后再学习。

## Docker / NAS 准备，未部署验收

保留 Dockerfile 与 compose.yaml；只复制应用、课件和静态源码，普通用户运行、应用只读，仅挂载专用数据目录。构建需官方镜像及软件源网络；本轮没有构建镜像、操作 NAS 或改变网络。

```bash
mkdir -p data
# 目录应属于实际容器 UID/GID；不要 chmod 777。
docker compose build
docker compose up -d
```

默认绑定宿主 127.0.0.1。任何家庭局域网开放都应先核对网络与主机设置；不要直接公开到互联网。

## 开发验证

```bash
python3 -m unittest discover -s tests -v
node --test tests/client.test.mjs tests/illustrations.test.mjs
node --check static/app.js
```

Node 18+ 仅用于测试。客户端集成测试使用轻量 DOM 适配器与真实临时 HTTP/SQLite，**不是浏览器、触控或声音验收**。3000 字容量测试使用人工合成汉字 fixture，不是已审核的教育字表。

严格真实浏览器验收（需已有 Playwright 和可启动 Chromium）：

```bash
python3 tests/run_browser.py
# 非默认 Chromium 路径可设置 BROWSER_EXECUTABLE。
```

该门禁遇到失败、跳过或零用例会退出失败，不能用普通套件的浏览器跳过结果代替。环境与模拟数据边界见 [tests/README.md](tests/README.md)。

`python3 scripts/audio.py` 仍会因未公开的 WAV 缺失报错；这是缺失实况，不影响成人/静音路径，也不代表读音或许可验收。不要为本轮自动生成、下载或上传许可未明音频。见 [素材来源与发布边界](ASSET_PROVENANCE.md)。
