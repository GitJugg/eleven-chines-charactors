# 小芽识字屋

原创家庭识字小网站，为 5 岁孩子与家长一起使用而准备。7 课、35 个不同汉字，每课 5 个新字。以安卓平板、家庭 Wi-Fi 和未来 NAS 托管为目标。

## 当前交付状态

这是公开源码与测试快照，不是已经部署的 NAS 网站，且不包含尚未核实公开再分发许可的 86 段 WAV，不能当作开箱即用的完整学习包。Python/SQLite/HTTP 和客户端状态逻辑已在云端验证；真实浏览器视觉/音频、安卓 Pad、Docker 构建及 NAS 部署尚未验收，不能将自动测试当作孩子实机体验通过。公开源码快照的复测范围与限制见 [STATUS.md](STATUS.md)。

当前界面：儿童首页、七日小花园、学习活动、暂停续学、家长统计、下载备份。

2026-10-25 视觉修订：新字配原创语义插图，配词的每个选项均配图，短句配故事场景；听音找字只显示中性听音角色，不用目标图透出答案。作答后在原选项显示大勾或温和的重试标记，并在选项旁显示大字号反馈与小芽鼓励；必须自己点“下一小步”，不会自动跳题。系统“减少动态效果”设置会关闭短动效。

本次入库没有改动应用行为或课程；语音二进制因再分发许可未确认而不公开提交，后续需替换为许可明确并完成核听的音频。当前仍保留 7 课、35 字基线，课程进阶尚未实现。没有修改课程版本、步骤ID、接口或数据库，已有进度可继续使用：备份后仅替换应用代码与 static 文件，保留整个原 data 目录，不要拿测试目录覆盖它。公开源码不等于公开部署运行中的网站；应用没有账号注册、广告或第三方追踪。

## 在一台可信电脑上检查源码（音频未就绪）

请先看 [素材来源与发布边界](ASSET_PROVENANCE.md)。直接从本仓库启动后，听音学习会因缺失 WAV 提示失败；不要让孩子使用这一不完整快照。补齐音频需要另行确认许可并同步核对文本、文件与 manifest，不能只改清单绕过校验。

需要 Python 3.11 或更新版本（Linux / macOS；Windows 建议用 Linux 容器）。生产服务不需要 npm，也没有第三方 Python 包依赖；系统需有时区数据库（tzdata），Dockerfile 已声明安装。

```bash
cd eleven-chines-charactors
python3 server.py
```

在同一台电脑打开 http://127.0.0.1:8080 。默认只监听本机。记录保存在该项目 `data/progress.sqlite3`，不是浏览器中；关闭再启动仍可接着学。每个数据目录只允许运行一个实例。

家庭局域网测试需先确认网络可信、服务器防火墙与 IP，再由家长设置：

```bash
DATA_DIR=/你的专用目录/sprout-data APP_TIMEZONE=Asia/Shanghai python3 server.py --host 0.0.0.0 --port 8080
```

Pad 浏览器访问 `http://服务器的局域网IP:8080`。不要填写本机的 127.0.0.1 到另一台 Pad。仅在可信家庭 Wi-Fi 使用；不要端口映射到互联网、不要开启路由器公网转发。本项目没有身份认证，局域网中能访问地址的人可以查看进度和下载备份；家长算术门槛只防孩子误触，不是密码保护。

## 怎么玩

1. 点击“开始今天的冒险”。每天是课程顺序，不是强制日历日期。
2. 第 1 课先热身；第 2～7 课先复习上一课全部 5 字，然后认识 5 个新字。
3. 点“听一听”，听完后进行听音找字、配词、短句。听音题不会额外展示目标字。声音失败时会明确提示，不能当作已经播放。
4. 答错也有温和反馈，记录尝试但不把完成当作掌握。每课结束固定得到 1 朵花，重复请求不重复领奖。
5. 随时“先休息一下”。服务器确认过的步骤自动保留。每天约 20 分钟仅为陪伴参考，不保证或强制时长；可以分几段，也可以慢一点。
6. 家长小窗查看本日小步、本周学习天数、每字答题表现和“建议再见一面”。第 7 课新字需要在课程结束后结合绘本或生活继续复习。页面不是专业能力评测。

没有排行榜、连续签到惩罚、随机奖励或孩子个人资料输入。不收集姓名、生日、照片、录音、位置。服务器只保存匿名步骤、作答、时间与固定奖励。服务器时区默认 Asia/Shanghai；本周从周一开始。请让主机时钟保持准确。

## 断连、刷新与多设备

- 每个页面一次只暂存 1 条待提交操作，以独立事件键保存；多标签遗留记录不会互相覆盖或删除。连接断开时会提示“还没有同步”，暂停后续答题；这不是离线学习。
- 不要清除浏览器数据或换设备，先在原设备点击“重新连接并同步”。服务器会用相同事件 ID 重试，已保存但响应丢失也不会重复计算。
- 同时在两台设备或两个标签学习可能触发进度冲突。选择“读取服务器进度”会放弃此设备未被服务器接受的那条暂存，以服务器为准，不覆盖已保存进度。
- 使用正常浏览模式并允许站点存储。若暂存不可用，页面不提交新答案；先检查存储权限。清除损坏暂存前会要求主动点击核对按钮。
- 不支持离线 PWA、APK 或多个儿童档案。

## 备份与恢复

家长小窗的“下载学习记录备份”通过 SQLite 在线备份接口生成一致快照。建议定期另存到可信设备；不要只靠同一块 NAS 磁盘里的副本。备份含匿名学习时间与答题记录，不宜公开分享。

恢复前：关闭所有学习页面；先恢复原页面待提交记录，或明确决定丢弃它们；停止服务。旧页面的暂存事件不应带入回退后的数据库。

```bash
# 停止 python 服务后，将下载的备份恢复到专用 data 目录
python3 scripts/restore.py /备份路径/sprout-backup.sqlite3 --data-dir ./data --confirm RESTORE
python3 server.py
```

恢复工具先检查数据库完整性、结构、课程版本、每条事件与固定奖励，拒绝不匹配或篡改的文件。只有检查通过才替换当前数据库；替换前保存 `progress.sqlite3.pre-restore-日期-随机标记` 副本。服务未停、存在未清理的数据库日志时拒绝替换。恢复失败时保留原数据。启动后刷新所有页面并核对家长统计。

当前课程版本 `sprout-2`。交接原型 `sprout-1` 的复习结构不同，不能直接恢复；原型没有真实孩子数据，本包没有加入自动迁移。以后修改课程结构应升级版本并另做迁移，不要直接改生产课件。

## Docker / NAS 准备（尚未部署验收）

提供 `Dockerfile` 与 `compose.yaml`，基于官方 Python 3.12 slim。镜像构建需要访问官方镜像仓库。容器用普通用户、只读应用目录，只挂载专用 `./data`，不需要或允许访问家庭照片等其他目录。

先核对极空间 Z4Pro 的 CPU 架构、容器引擎/Compose 支持和目录权限，再决定实际部署步骤。这些信息尚未核实，本包没有操作 NAS 或修改网络设置。以下是通用准备命令，不代表已在该 NAS 运行成功。

```bash
mkdir -p data
# 确保 data 属于实际运行容器的 UID/GID；不要使用 chmod 777。
# 默认 UID/GID 为 1000，可按确认后的环境设置 APP_UID / APP_GID。
docker compose build
docker compose up -d
```

默认仅发布在宿主 127.0.0.1，先在宿主测试。确认家庭网络与防火墙后，将 `LAN_BIND_IP` 设置为 NAS 的准确局域网 IP，例如放入同目录 `.env`（不要直接照抄示例地址）：

```text
LAN_BIND_IP=已核实的NAS局域网IP
APP_UID=已核实的用户UID
APP_GID=已核实的用户GID
```

再启动容器，Pad 访问该 IP 的 8080 端口。不改成公网域名、不做路由器端口转发。更新或重建镜像时保留专用 data 目录。

容器恢复示例，先停止服务，再运行一次性恢复任务：

```bash
docker compose stop sprout
docker compose run --rm --no-deps -v /备份目录:/backups:ro sprout python scripts/restore.py /backups/sprout-backup.sqlite3 --data-dir /data --confirm RESTORE
docker compose up -d sprout
```

这里仅额外只读挂载家长选择的备份目录，不要挂载整个 NAS 根目录。数据目录和备份应事先验证权限。

## 音频说明

原开发版本有 86 段 macOS Tingting 合成的 PCM WAV，仅用于家庭测试，公开再分发许可尚未确认。本公开仓库不含这些 WAV，只保留原创文本映射、既有哈希清单及校验脚本；清单不代表仓库附带了音频，也不授予任何音色许可。页面不依赖 Android 系统 TTS，因此缺少 WAV 会阻断听音学习。后续需换为许可明确的音频，再重新生成相应 manifest 并逐段核听。原文件的格式和哈希校验通过也不能证明读音正确。

先由家长在实际 Pad 上核听，再让孩子使用。重点核听“大 / 中 / 叶 / 长 / 地”等字音；“手足”例词有语义扩展，需要家长解释；“树上长着叶”口语略生硬，当前为了文音一致保留原句。修改词句必须同步重新生成对应音频。

```bash
python3 scripts/audio.py             # 本公开快照缺少 WAV，会按预期报错；不会改 manifest
# 仅在已获得音色使用许可的 macOS 上显式生成缺失/变更音频
python3 scripts/audio.py --generate
```

## 开发验证

```bash
python3 -m unittest discover -s tests -v
node --test tests/client.test.mjs tests/illustrations.test.mjs
node --check static/app.js
python3 scripts/audio.py
```

Node 18+ 只用于客户端逻辑测试；这些测试用 DOM 适配器连接真实 HTTP/SQLite，不是浏览器实测。家长页进入与每分钟刷新服务器数据，旧读取不会覆盖较新的提交结果；刷新失败明确显示上次读取的进度/日期。可选浏览器验收需要 Playwright 和可启动的 Chromium：

```bash
RUN_BROWSER=1 python3 -m unittest discover -s tests -p test_browser.py -v
```

已有浏览器验收未完成；本次源码入库不声明完成视觉、实际声音、触控或安卓兼容验收。详细复测结果见 STATUS.md。
