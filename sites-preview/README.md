# 小芽识字屋 · Sites 本机预览

基于公开项目 GitJugg/eleven-chines-charactors 的已测试版本 `8a44fe30674733f376b84ae4010528380658ff47`，保留基础 35 字、原创进阶 35 字、学习流程、配图、家长日历与目标设置。剩余 3000 字路径是规划，并非已完成课件。

## 用途与边界

- 这是静态 Sites 预览，不运行 Python/SQLite 服务，也不连接 NAS。
- 练习与目标仅写入当前浏览器的 IndexedDB，待保存答案放在隔离的本机 localStorage 键中；不发送学习记录、答案或目标到网络。
- 唯一应用数据请求是同源静态 `course.json`。没有分析统计、广告或外部资源。Sites 自身的托管与访问控制不由本应用实现。
- 不导入任何家庭真实学习记录。默认目标日期留空。请不要填入私人信息或把预览当作正式学习档案。
- 更换浏览器、设备或清除网站数据会丢失本机预览记录；无跨设备同步、NAS 同步、数据库导入、备份或恢复能力。
- 本预览不包含未获得再分发授权的语音文件，不提供试听音频按钮。成人带读和静音练习可用；不记为独立认读或掌握。
- 本机时钟不是服务器校时。日历固定按 Asia/Shanghai 统计，错误发生时间按本机保存时刻回退。
- 数据损坏或存储不可用会阻止继续保存，不自动删除或重置现有记录。

## 运行与验证

`dist/` 是完整静态发布目录，不需要安装依赖或构建。

运行：`node --test tests/*.test.cjs`

测试涵盖事件顺序与幂等、课程隔离、复习不重复奖励、日历分类与过滤、目标/日期校验、损坏数据拒绝、UI 步骤反馈/刷新继续/本机保存失败后重试。UI 测试使用小型 DOM 适配器，不是浏览器、真实 IndexedDB、截图、触屏或音频硬件验收。浏览器验收应单独进行。

## 维护

`dist/preview.js` 适配只用于 Sites，本项目不改变 NAS 源码或其 SQLite 迁移/备份行为。`dist/course.json` 来自上述版本的课程目录，移除本预览不存在的音频引用。原插画文件保持不变。
