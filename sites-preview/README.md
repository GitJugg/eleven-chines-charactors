# 小芽识字屋 · Sites 本机预览

基于公开项目 GitJugg/eleven-chines-charactors 的已测试版本 `8a44fe30674733f376b84ae4010528380658ff47`，保留基础 35 字、原创进阶 75 字、学习流程、配图、家长日历与目标设置。剩余 3000 字路径是规划，并非已完成课件。

## 用途与边界

- 这是静态 Sites 预览，不运行 Python/SQLite 服务，也不连接 NAS。
- 练习与目标仅写入当前浏览器的 IndexedDB，待保存答案放在隔离的本机 localStorage 键中；不发送学习记录、答案或目标到网络。
- 课程数据请求是同源静态 `course.json`。没有分析统计或广告。朗读只播放同源的预生成 MP3，不调用系统语音或运行时在线合成服务。生成阶段仅使用公开课程文本；学习记录、目标和私人日期不参与生成。Sites 自身的托管与访问控制不由本应用实现。
- 不导入任何家庭真实学习记录。默认目标日期留空。请不要填入私人信息或把预览当作正式学习档案。
- 更换浏览器、设备或清除网站数据会丢失本机预览记录；无跨设备同步、NAS 同步、数据库导入、备份或恢复能力。
- 认字、词语、故事、听字、复习、题目指令和答题反馈统一使用 edge-tts 生成的微软晓晓普通话 MP3（zh-CN-XiaoxiaoNeural）。这是合成声音，不是真人录音。首次需要轻点播放，后续步骤尝试自动播放，浏览器限制时可再点重听。只有播放器报告实际开始且完整结束后才开放答题/继续。文件缺失、播放失败、取消或超时不算完成，也不降级到系统语音；成人带读和静音仅作折叠可选方式。实际音量、发音和移动设备播放需另做实机验收。
- 本机时钟不是服务器校时。日历固定按 Asia/Shanghai 统计，错误发生时间按本机保存时刻回退。
- 数据损坏或存储不可用会阻止继续保存，不自动删除或重置现有记录。

## 运行与验证

`dist/` 是静态发布目录，不需要前端依赖或构建。公开源码包含文本清单但不提交 MP3；尚未确认音频公开再分发许可。发布包必须另行放入 `dist/audio/` 的全部实际 MP3，不能将只有源码的目录当成音频完整版本。

运行：`node --test tests/*.test.cjs`

测试包含实际 MP3 播放引擎的状态机（仅 Audio 硬件边界替身，非真实声音验收），取消、重播、失败、超时和完整结束解锁，以及所有课程的朗读文本覆盖。测试涵盖事件顺序与幂等、课程隔离、复习不重复奖励、日历分类与过滤、目标/日期校验、损坏数据拒绝、UI 步骤反馈/刷新继续/本机保存失败后重试。UI 测试使用小型 DOM 适配器，不是浏览器、真实 IndexedDB、截图、触屏或音频硬件验收。浏览器验收应单独进行。

## 维护

`dist/preview.js` 适配只用于 Sites，本项目不改变 NAS 源码或其 SQLite 迁移/备份行为。`dist/course.json` 来自上述版本的课程目录，移除本预览不存在的音频引用。保留原插画构图与语义，本轮统一更新蓝绿配色。

## 自由选课与内容预览

基础 7 课、进阶 15 课都可直接选择，不再要求先完成前一课。每课卡片显示字表，并可先打开“看看内容”查看词语、故事和练习类型；仅浏览不生成学习事件。可以直接从第 5 课开始，跳过的课保持未完成。每课仍按自己的步骤保存进度，刷新后继续；重复练习只要求该课首次完成，不会重复发放首次小花。

## 直接进入学习与旧记录兼容

开始课程直接进入认字或复习，不再展示仅含开场说明的“出发前，听一听”步骤。课程概览和练习进度只计可见步骤。课程版本、课时 ID 和原始步骤索引保持不变；跳过开场不生成学习事件。已保存的旧开场记录及其原日期、奖励与日历统计保持原样；尚未保存的旧开场答案仍可正常重试且幂等。首次学习、刷新继续和重复练习均从下一道真实练习开始。

## 故事理解题的答题依据

理解题保留本课完整短故事与对应插画，选项提供逐项审核的语义图片，不以通用装饰图替代。朗读包含故事、问题和全部选项，可重听找回上下文；答题后的讲解引用故事依据。此类练习是有图文与声音支持的理解活动，不是无提示识字测评。原课程数据、步骤索引和已保存记录不变。

## 后续生活单元

进阶第 8–15 课已追加：看书与表达、家人、起床穿衣、清洁、早餐、餐具和整理书桌。每课 5 个新目标字，共新增 40 字；全部已发布内容合计 110 个不同目标字。旧基础和进阶前 7 课数据与步骤保持不变。第 16–28 课仅为待制作目录，没有学习按钮；完整 3000 字路线是内容容量规划，不是已交付课件或掌握承诺。长期规划默认折叠，目标日期只读取本机设置。

新字“只”的朗读提示使用“一只小鸟”的词语语境，降低孤立多音字误读风险；文本测试不代表实际音色和发音验收。“了、只、和、的、好”在目标字提示和单字纠错中加入词语语境。

## 录音资源与发布检查

`audio-manifest.js` 必须先于 `speech.js` 加载；文本按 NFC + trim 查找固定 `audio/<文本 SHA-256>.mp3` 路径。播放点击不会先等待摘要计算或清单请求，避免消耗手机浏览器的播放授权。课程文本变更后必须重新生成清单与对应录音，不能只修改文件名。

- `node scripts/verify-audio-assets.cjs`：核对全部课程提示及所有反馈分支与文本清单一致，不证明音频文件存在。
- `node scripts/verify-audio-assets.cjs --assets`：发布前核对实际录音文件；缺文件或非法音频时必须阻止发布。
- MP3 由获授权的生成环境按清单生成；网页本身不需要 API 密钥。不要把密钥、私人记录或机器路径加入公开仓库。
- 不承诺网页离线缓存；页面和音频仍需从托管站点加载。代码测试通过不等于实际音频、移动端或上线版本已验收。
